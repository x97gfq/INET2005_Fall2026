Week 10: Assignment 4, Then React

The first class this week is an Assignment 4 work session: the trivia game, due Sunday. We start by making your first AI Chat Completions call from the terminal, with your key in .env (the same fetch() pattern as last week's Open-Meteo weather route, plus a key). Then we think the game through before building it: what happens in one round, where the correct answer and the score should live (on the server, never in the page), how to read the question and answer out of the AI's reply, how to keep only the last 100 questions and avoid repeats, and how to check an answer fairly. The rest of the class is work time, with checkpoints and help in the room.

On Friday we start React, from the ground up. You already know React from PROG 2700. What's new is everything around it: where it fits next to the API we've built since week 4, scaffolding a Vite app from the terminal, and running it in its own Docker container. Then the React itself, one step at a time: JSX, your first component, props, and the two hooks you'll use most, useState and useEffect.

What we'll cover

  • A first AI call from Node: fetch(), a timeout, checking res.ok, the key in .env
  • Designing the trivia game: one round from Start to score, and what lives on the server vs in the page
  • Reading the question and answer out of the AI's reply, and what to do when it ignores your format
  • Keeping the last 100 questions, and two ways to avoid repeating one
  • Checking answers fairly (trim, lowercase, punctuation), keeping score, and client-side validation
  • The big picture: React, our Express server, the movies API and MongoDB
  • Client-side vs server-side rendering: what View Source tells you
  • Scaffolding a React app with Vite from the terminal, in its own container; hot reload and Vite's proxy
  • JSX, components and props; lists and keys
  • Hooks: useState (a like button, a live search) and useEffect (asking our server), and the rules of hooks
